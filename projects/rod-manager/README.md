# Rod Manager

Rod Manager is a community portal for small groups that need a simple place to publish pages and manage member access.

## Features

- Public pages for community content
- Member accounts
- Password sign-in and OAuth sign-in
- Account settings and authentication management
- Protected page management for signed-in users
